# Using the Smart Gateway

This folder contains the **general configurations** for the Smart Gateway: once the platform is already deployed and running, these manuals walk you through configuring users, connecting SAP, streaming data to downstream destinations, and monitoring the whole pipeline.

> ℹ️ Looking to deploy the Smart Gateway infrastructure itself (on AWS, Azure, or SAP BTP)? See the [AWS](../AWS/), [Azure](../Azure/), or [BTP](../BTP/) folders instead. This folder assumes the platform is already up and reachable in a browser.

---

## 📚 Manuals in This Folder

### 1. [Configuring the Email Service (SMTP)](./01-Configuring_Email_Service_SMTP.md)

How to connect an SMTP server (ZeptoMail, SendGrid, Gmail SMTP, or a corporate mail server) to the platform's email builder deployment in Kubernetes. This is a foundational step — user activation emails and log alert notifications both depend on it.

### 2. [Adding New Users](./02-Adding_New_Users.md)

How an administrator creates new user accounts and approves them so they can log in. Requires the Email Service (step 1) to be configured first.

### 3. [Creating a SAP Link](./03-Creating_a_SAP_Link.md)

How to create an SAP Connector (SAP Link): defining it, configuring its Kafka connection (Confluent Cloud or Confluent Platform), setting topic partitions/replicas/retention, and sizing its container resources. This produces the endpoint URL used in SAP's `SM59` RFC destination.

### 4. [Configure Kafka Connect](./04-Configure_Kafka_Connect.md)

How to provision a Kafka Connect deployment for an existing SAP Link — required before any specific connector (Snowflake, Databricks, ClickHouse, etc.) can be added.

### 5. [Creating Connectors](./05-Creating_Connectors.md)

How to add a specific destination connector (Snowflake, Databricks, Hana, SQL Server, PostgreSQL, DB2, BigQuery, Amazon S3, Microsoft Fabric) to a configured Kafka Connect deployment, including topic selection and insert/upsert behavior.

### 6. [SAP Link Access](./06-SAP_Link_Access.md)

How an administrator grants another user access to an existing SAP Link, so multiple team members can collaborate on the same connector.

### 7. [Working with Logs](./07-Working_with_Logs.md)

How to filter, inspect, and export the Producer/Consumer/SAP activity logs generated by a SAP Link, and how to set up email notifications for `ERROR`/`FATAL` log events.

### 8. [Generating a SAP OTel Bridge Endpoint (Traceability)](./08-Generating_SAP_OTel_Bridge_Endpoint.md)

How to generate a Traceability endpoint that, once configured in SAP, surfaces SAP-side errors inside the OneConnect Logs section — correlating SAP issues with Kafka-side activity in a single view.

### 9. [Enabling Log Email Alerts](./09-Enabling_Log_Email_Alerts.md)

The Kubernetes-level environment variables (`oneconnect-logs`, `frontendoneconnect`) required to fully enable email alerts for `ERROR`/`FATAL` logs. Requires the Email Service (step 1) to be configured first.

### 10. [Environment Variables Reference](./10-Environment_Variables.md)

Reference documentation for the web application's environment variables (e.g. `NEXT_PUBLIC_SMTP_ENABLED`). Not a sequential step — consult it whenever you need to look up what a variable controls.

## 🚀 Recommended Reading Path

### If you are setting up the platform for the first time (administrator)

1. [Configuring the Email Service (SMTP)](./01-Configuring_Email_Service_SMTP.md)
2. [Adding New Users](./02-Adding_New_Users.md)
3. [Creating a SAP Link](./03-Creating_a_SAP_Link.md)
4. [Configure Kafka Connect](./04-Configure_Kafka_Connect.md)
5. [Creating Connectors](./05-Creating_Connectors.md)

### If you only need to add a new connector to an existing SAP Link

1. [Configure Kafka Connect](./04-Configure_Kafka_Connect.md) (skip if already configured)
2. [Creating Connectors](./05-Creating_Connectors.md)

### If you need to give a teammate access to an existing SAP Link

1. [SAP Link Access](./06-SAP_Link_Access.md)

### If you are monitoring or troubleshooting a running SAP Link

1. [Working with Logs](./07-Working_with_Logs.md)
2. [Generating a SAP OTel Bridge Endpoint (Traceability)](./08-Generating_SAP_OTel_Bridge_Endpoint.md)
3. [Enabling Log Email Alerts](./09-Enabling_Log_Email_Alerts.md)

### If you need to diagnose a specific issue

See [Troubleshooting](../../Troubleshooting/), starting with the [symptom triage table](../../Troubleshooting/README.md#-start-here-symptom-triage). The manuals above cover how to read the logs; the Troubleshooting guides cover how to interpret what they show and which settings to check next.
